# Amniora brand assets

`app/components/BrandLogo.tsx` combines an approved icon with the live Amniora
wordmark.

Active mappings:

- Dark backgrounds: `amniora-icon-white-cropped.png`
- Light backgrounds: `amniora-icon-navy-cropped.png`

The cropped files remove transparent canvas only. Their source artwork is
unchanged, and the original `amniora-icon-blue.png` and
`amniora-icon-navy.png` files remain available.

Other approved assets:

- Icon variants: `amniora-icon-black.png`, `amniora-icon-white.png`
- Horizontal logos: `amniora-logo.png`, `amniora-logo-dark.png`,
  `amniora-logo-light.png`
- Wordmarks: `amniora-wordmark-navy.png`, `amniora-wordmark-white.png`

`amniora-icon-white-cropped.png` is mechanically cropped from the approved white icon to remove transparent canvas only; the visible artwork pixels are unchanged.
